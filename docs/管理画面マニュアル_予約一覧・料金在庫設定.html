HOTEL PG 管理画面マニュアル

料金・在庫設定の操作ガイド

〜「予約一覧」「料金・在庫設定」編〜

このマニュアルは、ホテルスタッフが管理画面で 料金・在庫・予約受付期間 を設定するための手順書です。

対象は左メニューの 「予約一覧」 と 「料金・在庫設定」 の2つです。

0. ログイン方法

  1. ブラウザで管理画面を開きます：https://hotelpg-innosima.com/admin
  2. パスワードを入力してログインします。
  3. ログインすると、左側にメニューが表示されます。
左メニュー内容
予約一覧※現在は使用しません（下の「1章」参照）
料金・在庫設定料金・在庫・予約受付期間など。このマニュアルのメイン
ブログブログ記事の編集（本マニュアル対象外）
コンテンツ・写真トップページ等の文章・写真（本マニュアル対象外）
  • 画面下の 「サイトを開く」 で公開サイトを別タブで確認できます。
  • 作業が終わったら 「ログアウト」 してください。

1. 予約一覧について

左メニューの「予約一覧」を開くと、次のように表示されます。

公開サイトからの予約・空室は SaaS 側で管理しています。この管理画面の一覧は利用していません。

つまり、予約の確認はこの画面ではできません。
予約内容の確認は、これまでどおり SaaSの管理ツール（HotelPG オペレーション）や楽天などの管理画面 で行ってください。

2. 料金・在庫設定

左メニューの 「料金・在庫設定」 を開きます。このページには、上から順に 4つのブロック があります。

  1. 部屋タイプ（料金・在庫）
  2. 予約受付期間（何ヶ月先まで）
  3. 人数別在庫上限
  4. 期間別料金

⚠️ 最重要：保存ボタンはブロックごとに分かれています

このページには 保存ボタンが3か所 あります。変更したブロックの保存ボタンを押さないと反映されません。

変更した場所押す保存ボタン
部屋タイプ ／ 人数別在庫上限「SaaS に保存」
予約受付期間「受付期間を保存」
期間別料金「変更を保存」（新規追加は「この内容を追加して保存」）

1つのブロックを直したら、そのブロックの保存ボタンを押す——と覚えてください。

2-1. 部屋タイプ（料金・在庫）

ホテル（施設コード PG1 / PG2 / PG3）ごとに、部屋タイプのカードが並んでいます。各カードで、その部屋の 料金・人数・在庫 を設定します。

項目意味・使い方
有効（チェック）チェックを外すと、その部屋を販売停止（サイトに出さない）にできます。
表示名お客様に表示される部屋名です。
property_code / room_typeシステム上の識別番号です。基本さわらないでください（変えると正しく動かなくなります）。
平日（円）平日1泊あたりの料金。
金（円）金曜泊の料金。
土（円）土曜泊の料金。
基本人数（料金に含む）この人数までは基本料金で泊まれます。
追加1人（円）基本人数を超えた場合の、1人あたり追加料金。
最大人数その部屋に予約できる上限人数。
販売在庫上限同じ日に販売する部屋数（室数）の上限。

操作手順

  1. 変えたい部屋カードの数字を直接書き換えます。
  2. ページ下の 「SaaS に保存」 ボタンを押します。
  3. 「保存しました」と緑色で出れば完了です。

💡 値段を変えても、保存ボタンを押すまでは反映されません。

2-2. 予約受付期間（何ヶ月先まで）

「今日から何ヶ月先まで予約を受け付けるか」 を部屋ごとに設定できます。「3ヶ月より先はまだ予約させたくない」といったときに使います。

操作手順

  1. 部屋ごとのカードにある 「受付期間」 のプルダウンを選びます。
    • 無制限（ずっと先まで） … 制限なし（これまでどおり）。
    • 1ヶ月先まで 〜 12ヶ月先まで … その期間より先は予約不可になります。
  2. 「受付期間を保存」 ボタンを押します。

設定すると、どうなる？

  • 例：「3ヶ月先まで」にすると、3ヶ月より先の日付は、公式サイトの予約カレンダー上で 「受付期間外」 と表示され、予約できなくなります。

ℹ️ 注意：これは「この公式サイトの予約カレンダー」だけに効きます。

楽天トラベルなど他の予約サイトには影響しません（そちらは別途、各サイトで設定してください）。

2-3. 人数別在庫上限

人数帯（〇名〜〇名）ごとに、販売できる室数の上限を細かく決める表です。主に PG3 など、人数によって出せる部屋数を変えたい場合に使います。

列意味
property施設コード（PG1 / PG2 / PG3）
room_type部屋タイプ
min人数帯の下限
max人数帯の上限
在庫上限その人数帯で販売する室数

操作手順

  • 値を選び直す → ページ下の 「SaaS に保存」 で保存（※部屋タイプと同じ保存ボタンです）。
  • 行を増やす：「行を追加」。
  • 行を消す：右端の ゴミ箱アイコン。

💡 通常運用では基本さわりません。必要なとき以外は変更しないでください。

2-4. 期間別料金

お盆・連休・イベント期間など、特定の期間だけ料金を変えたいとき に使います。ここで設定した料金は、通常料金より優先されます。

登録済みの料金は、一覧で次のように表示されます（折りたたみ式）。

例：花火大会前料金 ｜ 2026/07/17 ｜ HOTEL PG -I- ｜ ¥12,000 / 泊
  • 行をクリックすると開いて編集できます。もう一度クリックで閉じます。
  • 右端の ゴミ箱アイコン で削除できます。

入力項目

項目意味
設定名管理用の名前（例：お盆料金、年末年始料金）。
開始日 / 終了日この特別料金を適用する期間。1日だけなら同じ日を入れます。
対象の部屋どの部屋に適用するか。
料金この期間の1泊料金。「平日・金曜・土曜で金額を分ける」にチェックすると曜日別に設定できます。
販売数をこの期間だけ変更する（任意）この期間だけ販売室数を変えたいときにチェック。
詳細設定（任意）料金に含む人数・追加1人料金を個別に変えたいとき。
この料金を有効にするチェックを外すと、その期間料金を一時的に無効化できます。

新しく追加する手順

  1. ページ下の 「新しい期間別料金を追加」 のフォームに入力します。
  2. 「この内容を追加して保存」 ボタンを押します。

既存の内容を直す手順

  1. 一覧の行をクリックして開き、内容を直します。
  2. 「変更を保存」 ボタンを押します。

3. よくある質問・困ったとき

Q. 変更したのにサイトに反映されない。
→ そのブロックの 保存ボタン を押しましたか？（2章冒頭の表を確認）。押した後「保存しました」と緑色で出るのが目印です。

Q.「Supabase が未設定のため、この設定は保存できません」と黄色い表示が出る。
→ 予約受付期間の保存に必要な設定が反映されていない状態です。サイト担当者（開発者）に連絡してください。

Q. property_code や room_type を間違えて変えてしまった。
→ 保存せずにページを再読み込みすれば元に戻ります。保存してしまった場合はサイト担当者に連絡してください。

Q. 予約の一覧・入金状況を確認したい。
→ この管理画面ではなく、SaaSの管理ツール（HotelPG オペレーション）や楽天の管理画面で確認してください。
